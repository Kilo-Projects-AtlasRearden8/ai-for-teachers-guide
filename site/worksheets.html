Before you start

Decide: subject and grade level, topic (one topic per worksheet), number of questions, question types (short answer, multiple choice, matching, fill-in-the-blank), and whether you want an answer key.

Do not include student names, grades, or personal information. Keep worksheets generic — use "Student" or leave name lines blank. See Privacy and safety.

Step by step

  1. Open a new chat in your free AI tool.
  2. Describe the worksheet. Include grade, subject, topic, question count, and question types.
  3. Ask for an answer key too. Request correct answers separately, so they do not end up on the student copy.
  4. Review everything. Check each question for accuracy and clarity. Make sure answer choices are not ambiguous.
  5. Copy into a document. Paste into Google Docs, Word, or your editor. Format with headings, spacing, and a name/date line.
  6. Print a test copy. Check spacing and page breaks before printing for the class.

Example prompt (copy and adapt)

I am a third-grade teacher. Create a 10-question worksheet on single-digit multiplication. Use 6 short-answer questions and 4 word problems. Keep the language simple. Provide a separate answer key with the correct answers. Do not include any student names.

Tips

  • One page is often enough. If the output is long, ask the AI to shorten it.
  • Mix difficulty. Ask for "3 easy, 4 medium, 3 hard" questions.
  • Answer key on a separate page. Copy the answer key into its own document before printing for students.
