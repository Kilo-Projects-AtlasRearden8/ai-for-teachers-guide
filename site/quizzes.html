Before you start

Decide: subject, grade level, and topic; quiz length; question types (multiple choice, true/false, short answer); and whether it is a practice or graded quiz.

Do not include student names, grades, or personal information. Keep quiz content generic. See Privacy and safety.

Step by step

  1. Open a new chat in your free AI tool.
  2. Describe the quiz. Include topic, grade, number of questions, and question types.
  3. Ask for a separate answer key. Request correct answers listed separately, not marked on the student quiz.
  4. Review every question. Check that each question has one clearly correct answer. Fix unclear wording.
  5. Format the quiz. Copy into a document. Add a name line, date line, and clear instructions at the top.
  6. Print a test copy. Check that it fits on one or two pages and that the answer key is separate.

Example prompt (copy and adapt)

I am an eighth-grade history teacher. Write a 12-question quiz on the American Revolution. Use 8 multiple-choice questions with 4 answer choices each, and 4 short-answer questions. Provide a separate answer key. Keep questions appropriate for eighth graders and do not include student names.

Tips

  • Ask for answer explanations. A one-sentence explanation per correct answer helps when reviewing with the class.
  • Multiple versions. Ask the AI to rewrite the same questions in a different order for a second version.
  • Keep answer keys secure. Store answer keys separately from student copies.
