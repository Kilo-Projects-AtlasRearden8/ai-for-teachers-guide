# AI for Teachers: A Beginner's Manual

A plain-English, step-by-step guide to using free AI for teaching work: lesson plans, worksheets, quiz questions, and parent emails. Built and published by **Asdale Dynamics, LLC**.

## Who this is for

Teachers, tutors, and homeschool parents who want to save time with AI but don't want to wade through jargon. You do not need to be technical. You do not need to pay for anything. Everything here works with free AI models.

## What is inside

**docs/ — the manual (Markdown)**
- `01-getting-started.md` — what AI is, picking a free model, creating an account safely
- `02-free-ai-models.md` — free models you can use today, with no credit card required
- `03-lesson-plans.md` — step-by-step: writing lesson plans with AI
- `04-worksheets.md` — step-by-step: building worksheets
- `05-quizzes.md` — step-by-step: writing quiz questions
- `06-parent-emails.md` — step-by-step: drafting parent emails
- `07-privacy-safety.md` — the most important rules: never paste student names or grades
- `08-printable-templates.md` — how to print the templates
- `templates/` — fill-in-the-blank templates you can print and use

**site/ — the same manual as a static HTML website**
- `index.html` — home and overview
- `lesson-plans.html`, `worksheets.html`, `quizzes.html`, `parent-emails.html` — each guide as a printable page
- `templates/` — printer-ready template pages
- `css/style.css` — clean styles, including print layout
- No build step, no server, no tracking. Open any `.html` file in your browser.

## The golden rule

**Never paste student names, grades, ID numbers, or any other personal student information into an AI tool.** Treat AI like a public whiteboard: only share what you would feel comfortable writing on the board for the whole school to see. See `docs/07-privacy-safety.md`.
