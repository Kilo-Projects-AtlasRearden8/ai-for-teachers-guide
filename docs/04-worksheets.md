# 4. Worksheets

AI is handy for drafting worksheet questions, instructions, and answer keys. You design the layout; AI drafts the content.

## Before you start

Decide:

- Subject and grade level
- Topic (one topic per worksheet works best)
- Number of questions
- Question types (short answer, multiple choice, matching, fill-in-the-blank)
- Whether you want an answer key

**Do not include student names, grades, or personal information.** Keep worksheets generic — use "Student" or leave name lines blank.

## Step-by-step

**Step 1. Open a new chat** in your free AI tool.

**Step 2. Describe the worksheet.** Include grade, subject, topic, question count, and question types.

**Step 3. Ask for an answer key too.** Ask the AI to label correct answers separately, so you do not mix them into the student copy.

**Step 4. Review everything.** Check each question for accuracy and clarity. Make sure answer choices are not ambiguous.

**Step 5. Copy into a document.** Paste into Google Docs, Word, or your preferred editor. Format with headings, spacing, and a name/date line at the top.

**Step 6. Print.** Print a test copy first to check spacing and page breaks (see `08-printable-templates.md`).

## Example prompt (no student data)

> I am a third-grade teacher. Create a 10-question worksheet on single-digit multiplication. Use 6 short-answer questions and 4 word problems. Keep the language simple. Provide a separate answer key with the correct answers. Do not include any student names.

## Tips

- **One page is often enough.** If the output is long, ask the AI to shorten it.
- **Mix difficulty.** Ask for "3 easy, 4 medium, 3 hard" questions.
- **Answer key on a separate page.** Copy the answer key into its own document before printing for students.
