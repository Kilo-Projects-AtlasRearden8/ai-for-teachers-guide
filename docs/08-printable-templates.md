# 8. Printable Templates

This manual includes fill-in-the-blank templates you can print and complete by hand, no computer needed during lesson time.

## Templates included

| Template | File |
|----------|------|
| Lesson plan | `docs/templates/lesson-plan.md` |
| Worksheet | `docs/templates/worksheet.md` |
| Quiz | `docs/templates/quiz.md` |
| Parent email | `docs/templates/parent-email.md` |

The same templates exist as printable web pages in `site/templates/`.

## How to print from the Markdown files

1. Open `docs/templates/` in your file explorer.
2. Open a template file in any text editor (Notepad, TextEdit, VS Code, etc.).
3. Print from the editor (File → Print), or copy the text into a word processor and print there.
4. Fill in the blanks by hand.

## How to print from the website

1. Open `site/index.html` in your browser.
2. Go to Templates in the menu, or open a template page directly (for example, `site/templates/lesson-plan.html`).
3. Press Ctrl+P (Windows) or Command+P (Mac) to print.
4. The pages are styled for printing — headers and navigation hide automatically, leaving a clean form.

## Fill-in-the-blank rules

- Write in pencil if you might change things.
- Never write student names or grades on templates you might share or scan into an AI tool.
- Keep completed templates with your personal planning notes, not in a public folder.
