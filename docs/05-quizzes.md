# 5. Quiz Questions

AI can draft quiz questions quickly. You verify the answers and format the quiz for your class.

## Before you start

Decide:

- Subject, grade level, and topic
- Quiz length (number of questions)
- Question types (multiple choice, true/false, short answer)
- Whether it is a practice quiz or a graded quiz

**Do not include student names, grades, or personal information.** Keep quiz content generic.

## Step-by-step

**Step 1. Open a new chat** in your free AI tool.

**Step 2. Describe the quiz.** Include topic, grade, number of questions, and question types.

**Step 3. Ask for a separate answer key.** Request that correct answers be listed separately, not marked on the student quiz.

**Step 4. Review every question.** Check that each question has one clearly correct answer. Fix any trick questions or unclear wording.

**Step 5. Format the quiz.** Copy into a document. Add a name line, date line, and clear instructions at the top.

**Step 6. Print a test copy.** Check that it fits on one or two pages and that the answer key is separate (see `08-printable-templates.md`).

## Example prompt (no student data)

> I am an eighth-grade history teacher. Write a 12-question quiz on the American Revolution. Use 8 multiple-choice questions with 4 answer choices each, and 4 short-answer questions. Provide a separate answer key. Keep questions appropriate for eighth graders and do not include student names.

## Tips

- **Ask for answer explanations.** Request a one-sentence explanation for each correct answer — useful when reviewing with the class.
- **Multiple versions.** Ask the AI to rewrite the same questions in a different order for a second version of the quiz.
- **Keep answer keys secure.** Store answer keys separately from student copies.
